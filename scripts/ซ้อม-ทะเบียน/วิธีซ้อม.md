# เวทีซ้อมระบบสต็อกทะเบียน (รันบนเครื่อง ไม่กินเครดิต Netlify ไม่แตะของจริง)

> gucut2 สร้าง 22 ต.ค. 2569 ตามใบ "ทำดี ๆ" — ผลซ้อมรอบแรก (ตาราง 22 ข้อ) อยู่คลังทีม `ระบบทะเบียน-ออกแบบ.md`
> หลักคิด: **ตัวเตือนต้องเคยถูกทำให้ร้อง** — ด่านที่ไม่เคยแดงให้ถือว่ายังไม่เสร็จ

## ชิ้นส่วน
- `blobs-edge.mjs` — เซิร์ฟเวอร์ Netlify Blobs ปลอม (โปรโตคอล edgeURL) เก็บเป็นไฟล์ · **พิมพ์ทุกคำขอ**
  — ข้อนี้สำคัญ: บั๊ก Next แคช fetch ของ blobs (จอค้างของเก่า) เจอได้เพราะเห็นว่า GET ไหนไม่ยิงจริง
- `sim-apps-script.mjs` — ตรรกะเดียวกับ Apps Script จริง (`scripts/apps-script/registry-push.gs`) รันกับ
  ชีทจำลองโครงจริงหัวสองชั้น แล้วตรวจว่า **ซีเรียล/ชื่อผู้ซื้อ/ลซ./จังหวัดไม่หลุด** ก่อนยิงเข้า endpoint
  ⚠️ แก้ regex อนุญาต/ห้าม ใน .gs เมื่อไหร่ ต้องลอกมาที่นี่ด้วย (สำเนา ≠ ของร่วม — แล้วรันให้เขียวก่อน commit)

## เปิดเวที
```bash
# 1) ถัง Blobs ปลอม (ถังใหม่ทุกครั้ง — ที่ทดลองที่ใช้ซ้ำคือที่ทดลองที่มีของค้าง)
BLOBS_EDGE_DIR=/tmp/ซ้อม-$(date +%s) BLOBS_EDGE_PORT=8977 node scripts/ซ้อม-ทะเบียน/blobs-edge.mjs &

# 2) dev server ชี้ถังปลอม + คีย์ซ้อม (env ทดสอบของทีมอยู่ ~/gucut-test/env — ห้ามใส่คีย์จริง)
CTX=$(python3 -c "import base64,json;print(base64.b64encode(json.dumps({'edgeURL':'http://127.0.0.1:8977','uncachedEdgeURL':'http://127.0.0.1:8977','siteID':'rehearsal','token':'x'}).encode()).decode())")
set -a; source ~/gucut-test/env; set +a
NETLIFY_BLOBS_CONTEXT=$CTX REGISTRY_PUSH_KEY=ซ้อม-g2-rehearsal-key-2210 npx next dev -p 3002
```

## เมนูซ้อม (คาดหวังอะไร ดูตารางในบันทึกออกแบบ)
- **สคริปต์ → endpoint**: `node scripts/ซ้อม-ทะเบียน/sim-apps-script.mjs` (ต้องจบ ✅ ทุกข้อ)
- **ของเสีย**: ยิง payload กุญแจผิด/ไม่มีแท็บ/41 แท็บ ดู 401/400 · ปลูกไฟล์ `layout` ในถังแล้วส่งหัวเปลี่ยน ⇒ หยุด-หัวเปลี่ยน
- **ตัวเฝ้าความเงียบ**: แก้ `เมื่อ` ใน `log.blob` ให้เก่า 40 นาที แล้วรัน handler ของ
  `netlify/functions/registry-sheet-pull.mjs` ตรง ๆ (import default แล้วเรียก) — ต้องจดรอบแดง + เตือนครั้งเดียว + ฟื้นแล้วแจ้งกลับ
- **ขา g1**: `REGISTRY_FEED=http://localhost:3002/api/registry-sheet-run REGISTRY_KEY_FILE=<ไฟล์คีย์ซ้อม> REGISTRY_TARGET=/tmp/เป้าซ้อม.json python3 ~/bin/pull_registry_target.py --จริง`
  (สำรวจ ⇒ rc3 ไม่เขียน · ปลูก `latest.blob` ⇒ เขียน · ลบรหัสออก ⇒ rc7 ไม่ทับ)
- **ไฟล์สถานะ → จอ**: POST `/api/flow-status-upload` ด้วยคีย์ env ทดสอบ · ส่งขา `เมื่อ` เก่า 3 ชม. ⇒ จอต้องแดงเอง
- **ดูจอ**: ล็อกอินด้วย SITE_PASSWORD จาก env ทดสอบ แล้วเปิด `/core/registry`
  🔴 ห้ามถ่ายจอผ่าน Chrome 9222/9224 (โปรไฟล์คนอื่น — สกิล keep-sessions) · เปิด Chrome ของตัวเอง headless แทน

## ก่อนเชื่อผลเขียว
ปลูกบั๊กให้ด่านร้องอย่างน้อยหนึ่งตัวเสมอ (เช่นถอด `ผู้ซื้อ` จาก ห้าม **และ** เพิ่ม `ชื่อ` ใน อนุญาต ใน sim)
— ปลูกแล้วต้องยืนยันว่าปลูกลงจริง: การ์ดเป็นสองชั้น (default-deny + ห้าม) ถอดชั้นเดียวมันไม่ร้องเพราะไม่รั่วจริง
