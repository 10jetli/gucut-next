# วัดหน้าตาจอเรากับ ZORT เป็นตัวเลข (17 ต.ค. 2569)

ทุกสคริปต์ **อ่านอย่างเดียว** — เปิดแท็บใหม่ อ่าน `getComputedStyle` แล้วปิดแท็บ · ไม่กด ไม่พิมพ์ ไม่บันทึก
(ตรวจด้วย `grep -n "click\|fill(\|press(\|submit" scripts/zort-style/*.py` ต้องว่าง)

| สคริปต์ | วัดอะไร | เรียก |
|---|---|---|
| gen.py | หัวจอ · ปุ่มหัวจอ · หัวคอลัมน์ · ช่อง · ลิงก์ในแถว (หลายจอทีเดียว) | `python3 gen.py <พอร์ต> <โดเมน> '{"ชื่อ":"/path"}'` |
| gen2.py | ช่องค้นหา · dropdown · แท็บ · เลขหน้า | เหมือน gen.py |
| gen3.py | กรอบตาราง · หัวตาราง · แถวสลับสี · ช่องว่างในช่อง | เหมือน gen.py |
| det.py / det2.py | จอรายละเอียด (เปิดลิงก์แถวแรกจากจอรายการ) — ป้าย/ค่า/การ์ด | `python3 det.py <พอร์ต> <url จอรายการ> '<selector ลิงก์>'` |
| form.py | ฟอร์มสร้าง — ป้ายชื่อช่อง · ช่องกรอก · dropdown | `python3 form.py <พอร์ต> <url>` |
| dash.py · rep.py | แดชบอร์ด · จอรายงาน — การ์ด · ตัวเลขเด่น | `python3 dash.py <พอร์ต> <url>` |
| pager.py | ปุ่มเลขหน้าใต้ตาราง | `python3 pager.py <พอร์ต> <url>` |
| cols.py | ชื่อ+ลำดับหัวตาราง (หลายจอทีเดียว) | เหมือน gen.py |
| layout.py | แถบเมนู/แถบบน/ตำแหน่งหัวจอ | `python3 layout.py <พอร์ต> <url> [กว้าง]` |

พอร์ต: ZORT = 9223 · เว็บเรา (ล็อกอินแล้ว) = 9224 · วัดที่ **1280px ทั้งสองฝั่ง** (หน้าต่าง ZORT กว้าง 1280 ตายตัว)
