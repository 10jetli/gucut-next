# ของพักไว้ — ยังไม่ลบ รอเงื่อนไขครบแล้วเอากลับ

โฟลเดอร์นี้เก็บโค้ดที่ **ยังใช้ไม่ได้เพราะของที่มันพึ่งยังไม่มี** ไม่ใช่โค้ดที่เลิกใช้
ตั้งนามสกุล `.txt` ต่อท้ายเพื่อให้ **ไม่มีเครื่องมือไหนกวาดหรือคอมไพล์** (ด่าน · tsc · Next)

## `admin-log.page.tsx.txt` — สมุดคำสั่งหลังร้าน (พักไว้ 25 ก.ย. 2569)

**ทำไมถึงพัก**: หน้านี้เรียก `/api/core?adminlog=1` ซึ่ง **ไม่เคยถูกสร้างในฝั่ง gucut-web**
ยิงของจริงแล้วตอบ `{"fallthrough":true,"endpoint":"default"}` = คำตอบหน้าแรก ไม่ใช่เส้นจริง
และหน้านี้อ่าน 4 ช่องที่ไม่มีในซอร์สท่อเลย:
`เพดานแถวที่ส่งกลับ` · `เห็นครบทุกแถวไหม` · `เก็บกี่วัน` · `⚠️ ค่า hours ถูกปรับ`

⇒ ด่าน `scripts/check-pipe-keys.mjs` ตีตก ทำให้ **ทั้งรีโป build ไม่ผ่าน ทุกคน deploy ไม่ได้**
พิสูจน์แล้ว: ซ่อนงานที่กำลังทำอยู่ แล้ว build บน `main` สะอาดก็ตกด่านเดียวกัน
(ไม่ใช่ผลจากงานใหม่ — ไฟล์นี้แก้ล่าสุด 21 ก.ย. 2569)

**ท่านประธานอนุมัติให้ถอดชั่วคราว 25 ก.ย. 2569**
🔑 ไม่ขัดกับกติกา "อย่าลบเมนูเก่า" เพราะกติกานั้นคุ้มครอง **เครื่องมือที่ใช้งานได้**
หน้านี้เรียกท่อที่ไม่มีอยู่จริง ⇒ เปิดไปก็ได้จอว่าง

### เอากลับยังไง
1. สร้างเส้น `?adminlog=1` ใน `gucut-web/netlify/functions/core.mjs` ให้ส่ง 4 ช่องข้างบนจริง
2. `git mv parked/admin-log.page.tsx.txt app/core/admin-log/page.tsx`
3. ปลดคอมเมนต์บรรทัดเมนูใน `lib/nav-config.ts` (ค้นคำว่า `รอท่อ ?adminlog=1`)
4. `npm run build` — ด่านจะบอกเองถ้าชื่อช่องยังไม่ตรง
